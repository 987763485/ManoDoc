### 实机（macOS Apple Silicon，开发构建）

- 日志与诊断：设置页可调级别/保留天数；`~/.dull_doc/logs/<date>.jsonl` 记录任务 ID、引擎、目标、耗时、字数；导出诊断 zip 含 `diagnostics.json`（版本、平台、设置、最近任务）与最近日志，未包含文件正文。
- 关于：显示版本、MIT 协议名称、第三方许可与 pandoc 源码获取方式（按用户要求不展示协议正文）。
- PDF 预检：50 页 PDF 打开后列出第 1 页无文本层（2%）；「跳过并继续」直接开始转换，「使用 OCR 继续」「改为失败」「取消转换」可选。
- 图片资产：同一 PDF 的 Markdown 输出 130 处引用全部写入 `assets/chg006/image-*.png` 相对路径，文件存在；关闭图片模式时保留 alt 文本行为。
- 输出设置：图片模式（assets/base64/alt）、覆盖策略（自动重命名等）、历史保留条数 50 生效；同名文件生成 `-1`。
- 预设：内置标准文档/表格清单/知识库；用户预设可新建、复制、编辑重命名、删除、导入/导出。
- 全局体验：转换时标题栏显示「文件名 → 目标 4% ×」；切到转换历史后任务与进度保持；单文件拖入转换、多文件/文件夹拖入语料制作由组件测试覆盖。
- 引擎选择：显式选择写入 `settings.json`，换文件后保持；`auto` 为默认。
