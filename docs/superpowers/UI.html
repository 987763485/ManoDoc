输出、引擎、语言与主题

通用

语言与主题即时生效；应用数据统一存放在 ~/.dull_doc。

界面语言中文默认；英文完整；切换无需重启。
主题跟随系统、浅色或深色；所有颜色来自 token。
默认输出目录~/Documents/DullDoc Output
应用数据目录~/.dull_doc/settings/presets/history/logs/tmp/runtimes
文件夹访问输出目录与批量输入需要系统授权；失败时给出系统设置引导。

支持的方向

基础一对一转换；多引擎方向可在转换页选择。

PDF → Word 走 PDF → Markdown → Word，目录与图片保真有限；Markdown → PDF 由 pandoc + Typst 生成。Python 引擎由 uv 按需下载 Python，并在应用数据目录创建 .venv。
